# AWS Labs Documentation

A collection of hands-on lab documentation and walkthroughs for core AWS cloud concepts and services. This repository is organized by learning path and contains step-by-step notes, configurations, screenshots, and explanations for each lab.

## Cloud Foundations

Cloud Foundations is designed to introduce learners to the core concepts of cloud computing and the essential services offered by AWS. This course provides a strong foundational understanding of cloud architecture, security, storage, networking, databases, and pricing models, while also preparing students for future technical and professional opportunities in cloud technology

## Cloud Architecting

Cloud Architecting is designed to provide learners with the knowledge and practical skills required to design cloud-based solutions using AWS architectural principles and best practices. This course focuses on the fundamentals of cloud architecture, including designing resilient systems, implementing secure infrastructures, optimizing performance, managing storage and databases, and building highly available applications in the AWS environment.
